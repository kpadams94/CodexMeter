# Issue tracker: GitHub

Issues and specifications live in GitHub Issues for `kpadams94/CodexMeter`.

Use the GitHub CLI with `--repo kpadams94/CodexMeter` for all operations because a local checkout may not be available.

## Conventions

- Publishing to the issue tracker means creating a GitHub issue.
- Reading a ticket means fetching the issue body, comments, and labels.
- Labels are applied and removed through GitHub Issues.
- Pull requests are not treated as incoming feature requests.
